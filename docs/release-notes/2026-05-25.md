# TrendCue Release Note

**Date:** 2026-05-25  

## Summary

This release advances TrendCue from a single-user trend discovery prototype into a workspace-oriented application with improved media reliability, profile onboarding, organisation administration, and stronger access control.

## Delivered Updates

- Migrated the project from npm lockfiles to `pnpm` and updated setup documentation.
- Stabilised TikTok rendering by caching durable thumbnails, adding TikTok embed playback in the detail view, and moving search results onto real Supabase post data.
- Added project preview thumbnails and improved saving posts from the detail panel.
- Added a project deletion flow with confirmation, permission-aware failure handling, and cleanup of onboarding project references while preserving the original Discover posts.
- Enforced the Supabase password policy in configuration and sign-up validation.
- Added profile access from the dashboard avatar, including onboarding, industry preferences, and account summary.
- Added organisation workspaces: new sign-ups create an organisation, while invited users join an existing workspace.
- Moved saved projects toward organisation ownership with RLS-backed membership access.
- Added admin team management for invitations, role assignment, revocation, and member removal with last-admin protection.
- Added mock billing with tier selection, safe payment-method display metadata, invoice history, and authorised invoice downloads.
- Updated README architecture, database, roles, billing, and sample-data documentation.
- Captured implementation learnings for TikTok thumbnails and Supabase RLS migration issues.

## Validation

- `pnpm run lint` and `pnpm run build` were completed during implementation.
- Supabase migrations were applied to the linked project.
- RLS smoke checks verified member billing denial, removed-member project denial, last-admin protection, and non-admin invoice download denial.

## Scope Notes

Billing and invitation delivery remain intentionally mocked for the given scope. Real payments processing, with card number and CVC handling is to be implemented in the next release.
